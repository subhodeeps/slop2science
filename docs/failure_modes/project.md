# Failure modes of this project

This file is the failure log of this project. At `/session-close`, add an entry whenever
something went wrong. State **what happened**, **what it cost** and **what changed as a result**.
If nothing changed, the entry is still worth having. "We decided to accept this risk" is a
finding. Use the next free number, starting at `P1`. `docs/failure_modes.md` is the index of all
failure modes.
